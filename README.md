# snows-bedrock-server-tool
A tool meant to make hosting the vanilla minecraft bedrock server a little easier. Automagically sets up a discord bot to help manage the server and a bot that allows you to join the server from an xbox live friend.

# THIS TOOL IS A WIP
Primarly intended for a headless Ubuntu distro. I'm sorry if this won't work for you, it may work for other linux distros but I made this for me.
I do not like using docker or any other virtual environments. In my opinion it's wasting system resources for the point of wasting system resourves
